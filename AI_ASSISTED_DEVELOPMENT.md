# AI-Assisted Development Disclosure

Taskbar Monitor Enhanced was developed under human engineering control with assistance from AI-based tools.

AI-assisted tools were used as engineering support for tasks such as:

- drafting and revising code
- refactoring
- diagnostics and failure analysis
- test scaffolding
- documentation
- iterative review

They were not treated as an autonomous author or release authority.

Project requirements, architecture, design decisions, hardware validation, acceptance criteria, real-machine testing, licensing decisions, and release responsibility remained under human control.
