# Changelog

## 1.0.0

First public release of Taskbar Monitor Enhanced.

Highlights:

- CPU, RAM, disk, network, GPU and VRAM monitoring
- CPU Package and GPU temperature display
- 14 visual themes
- Live trends and taskbar-native presentation
- Right-click controls
- Explorer/taskbar recovery
- Protected sensor supervision architecture
- Windows startup support
- Tested installer upgrade, uninstall and clean installation flow
