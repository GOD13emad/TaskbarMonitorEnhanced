# Taskbar Monitor Enhanced

A lightweight Windows taskbar system monitor for live CPU, RAM, disk, network, GPU, VRAM and temperature telemetry.

## v1.2.0 — Modern Settings & Premium Themes

Version **v1.2.0** builds on the accepted v1.1.3 startup-resilience baseline and the unchanged **1.1.2+r21 protected sensor layer**.

This release focuses on three user-facing improvements:

- fixes the Settings-open hover-detail bug so the hardware flyout cannot open or remain stuck while Settings is active;
- redesigns Settings with a modern left-navigation shell, clear page hierarchy, dark surfaces, consistent controls and a live theme preview;
- doubles the built-in theme library from **14 to 28**, adding seven reusable renderer families rather than palette-only copies.

The protected CPU/GPU/storage architecture remains process-isolated and supervised. The main UI remains non-elevated.

## Install and uninstall

Use the official [GitHub Releases](https://github.com/GOD13emad/TaskbarMonitorEnhanced/releases) page. Verify published SHA-256 values before running an installer.

The application installs per-user under:

`%LOCALAPPDATA%\TaskbarMonitorEnhanced`

Uninstall through **Windows Settings > Apps > Installed apps > Taskbar Monitor Enhanced**, or run:

`%LOCALAPPDATA%\TaskbarMonitorEnhanced\Uninstall.exe /uninstall`

PawnIO is intentionally not removed automatically because another hardware-monitoring application may depend on it.
