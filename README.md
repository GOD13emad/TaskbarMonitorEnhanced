# Taskbar Monitor Enhanced

A lightweight Windows taskbar system monitor for live CPU, RAM, disk, network, GPU, VRAM and temperature telemetry.

## v1.3.0 — Reliability, Alerts & Support Tools

Version **v1.3.0** is the current public Latest release. It keeps the accepted R21 process-isolated sensor architecture while hardening Storage completion, continuously self-healing Start-with-Windows registration, and adding operational controls for alerts, battery-aware polling, diagnostics and support.

Key v1.3.0 changes:

- Storage one-shot success is now accepted from fresh validated output independently of near-boundary process-exit timing.
- Start-with-Windows primary and recovery registrations are verified and repaired periodically while enabled.
- CPU, GPU and disk temperature warning thresholds can drive high-visibility hot-state accents.
- Adaptive battery polling, Session Pause/Resume and configurable sparkline history depth are available.
- Diagnostics can be copied or exported as a privacy-hardened support ZIP.
- Safe Defaults creates a unique timestamped config backup before loading defaults into the Settings form; runtime state is unchanged until **Save & Apply**.
- Settings now has **9 pages**, including a dedicated Alerts page.
- Protected sensor protocol compatibility remains **1.1.2+r21** while the hardened Sensor Supervisor build is **1.3.0+r33**.

The main UI remains non-elevated. CPU/GPU/storage native sensing remains isolated and supervised.

## Install and uninstall

Download v1.3.0 from the [official GitHub release](https://github.com/GOD13emad/TaskbarMonitorEnhanced/releases/tag/v1.3.0). Verify `SHA256SUMS_v1.3.0.txt` before running the installer.

Installer SHA-256:

`508bb69f48d992ffc5af240f3f775b5e2caa1b052bfdb48302dec40364b521bf`

The application installs per-user under:

`%LOCALAPPDATA%\TaskbarMonitorEnhanced`

Uninstall through **Windows Settings > Apps > Installed apps > Taskbar Monitor Enhanced**, or run:

`%LOCALAPPDATA%\TaskbarMonitorEnhanced\Uninstall.exe /uninstall`

PawnIO is intentionally not removed automatically because another hardware-monitoring application may depend on it.
