# Privacy

Taskbar Monitor Enhanced is a local Windows taskbar system-monitoring application.

## Data handling

The application reads system telemetry from the local computer in order to display CPU, memory, disk, network, GPU, VRAM, and temperature information.

Taskbar Monitor Enhanced does **not** transmit monitoring telemetry, configuration data, or personal information to remote systems as part of its normal operation.

No analytics, advertising SDK, user tracking, or cloud telemetry service is included in the application.

## Network activity

Normal monitoring does not require the application to upload user data. Any future feature that intentionally communicates with a network service must be documented before release, including the service involved, the data exchanged, and whether the feature can be disabled.

## Third-party components

Taskbar Monitor Enhanced uses open-source and system-level components documented in `THIRD_PARTY_NOTICES.md`. Those components are included for local hardware monitoring and supporting functionality.
