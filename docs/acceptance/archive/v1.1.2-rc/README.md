# v1.1.2 Release-Candidate Archive

This directory contains historical engineering records from the v1.1.2 RC3–RC10 validation cycle.

- `RC_MANIFEST_*.json` records candidate-specific build and acceptance metadata.
- `SHA256SUMS_*.txt` records checksums for the corresponding candidate artifacts.

These files are retained for auditability only. They are **not current release downloads** and are intentionally kept outside the repository root to reduce clutter.

For current public artifacts, use GitHub Releases. For final acceptance evidence, see the parent `docs/acceptance/` directory.
