# Taskbar Monitor Enhanced v1.4.0

v1.4.0 is the Windows Integration & Accessibility release.

Highlights:
- PerMonitorV2 DPI awareness
- selectable discovered Windows taskbar monitor with safe Primary fallback
- Follow Windows app light/dark mode using configurable TBME theme pairs
- High Contrast and Settings accessibility metadata/keyboard navigation
- hardened canonical GitHub update identity and pre-launch SHA-256 re-verification
- hardened process DLL search path
- privacy-safe local crash snapshot and support-bundle inclusion

The protected sensor architecture is unchanged:
- Broker protocol 1.1.2+r21
- Sensor Supervisor 1.3.0+r33
- R21 process isolation retained

v1.3.1 and all previous public releases remain immutable.
Public trusted Authenticode signing is not claimed unless independently proven.
