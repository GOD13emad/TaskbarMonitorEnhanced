# Taskbar Monitor Enhanced v1.7.2

## Glass and taskbar corrections

- Glass is a separate pill-shaped ON/OFF control with a circular thumb. ON forces zero background opacity and disables the percentage control; OFF restores the previous value.
- Ordinary background opacity remains continuous from 1 to 100 percent without changing theme ink or adding a Glass halo below 31 percent.
- The monitor follows actual taskbar visibility, including a covered fullscreen taskbar. Start, Settings and context menus retain their positions; the monitor is owned by the taskbar rather than reparented during Start.
- Compact rendering respects the exact native window dimensions.

## One installation, protected update

The same versioned Setup installs or updates the single per-user TaskbarMonitorEnhanced root. Official 1.7.1 is recognized by the exact published Main, Setup and managed payload hashes. Version 1.6.0 and recognized 1.7.0 ancestors retain their guarded upgrade paths. Close the running monitor normally before updating; do not uninstall first. User configuration, backups, sensor backend, arbitrary files and Startup preference are preserved. Unknown or edited managed files fail closed.

The installer remains unsigned by explicit owner decision. A SHA256 match proves file identity, not a publisher signature or absence of malware.

## Acceptance boundaries

Consumer-PC sustained CPU, exclusive-fullscreen applications, hardware power-cut testing, and external antivirus reports require their own evidence. A successful build is not visual acceptance. This file describes the versioned changes and does not itself prove that 1.7.2 has been publicly released.
