# Taskbar Monitor Enhanced v1.6.0

v1.6.0 adds a full Performance Workspace, 20 original Studio themes (48 built-in themes total), richer local analytics and opt-in traffic history while preserving the protected sensor architecture from v1.5.0.

Key points:
- CPU, RAM, disk, network, GPU, VRAM and temperature monitoring.
- 48 built-in themes, including 20 new Studio designs with distinct renderer geometry.
- Eight-page Performance Workspace: Overview, Processes, Network, Storage, Alerts, Themes, Profiles and Hardware.
- Bounded session history with interactive charts, statistics JSON, chart PNG and CSV exports.
- Read-only process table with CPU, memory, thread and handle visibility.
- Per-adapter network view and optional 90-day local traffic accounting; persistence is off by default.
- Sustained CPU/RAM/GPU/disk-capacity notifications, quiet hours and global snooze.
- Presentation profiles and metric reordering without importing startup/sensor/notification security settings.
- Existing temperature alerts, accessibility, PerMonitorV2, High Contrast, self-heal and hardened updater remain.
- Protected sensor architecture remains process isolated; v1.6.0 does not modify broker/supervisor protocol versions.
- No cloud telemetry or background upload is introduced.
- No publicly trusted Authenticode signature is claimed unless independently verifiable on the published binary.
