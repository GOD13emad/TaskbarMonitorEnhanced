# Taskbar Monitor Enhanced v1.5.0

v1.5.0 adds actionable temperature notifications, bounded session telemetry CSV export and a Task Manager quick action while retaining the v1.4.0 Windows integration/accessibility baseline.

Key points:
- CPU, RAM, disk, network, GPU, VRAM and temperature monitoring.
- 28 built-in themes and renderer-backed theme preview.
- Optional Windows temperature notifications with hysteresis/cooldown.
- User-initiated bounded session CSV export from Diagnostics.
- PerMonitorV2 DPI, High Contrast and accessibility metadata.
- Protected sensor architecture remains process isolated.
- Automatic updates require canonical immutable GitHub release identity and SHA-256 verification.
- No publicly trusted Authenticode signature is claimed unless independently verifiable on the published binary.
