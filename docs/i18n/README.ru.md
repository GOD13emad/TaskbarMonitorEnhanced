# Taskbar Monitor Enhanced — Русский

Taskbar Monitor Enhanced — лёгкий системный монитор, встроенный в панель задач Windows. Он показывает основные показатели системы прямо на taskbar, без отдельного постоянно открытого окна.

## Текущая версия

**1.2.0 (source candidate; public release: v1.1.3)**

## Основные возможности

- CPU, RAM, диск, GPU и VRAM
- Отдельные скорости загрузки и отдачи
- Температуры CPU Package и GPU
- 28 встроенных тем
- Графики и sparklines в реальном времени
- Размещение слева, по центру или справа
- Настраиваемая ширина и безопасное позиционирование
- Контекстное меню по правому клику
- Автовосстановление после перезапуска Explorer
- Основное приложение работает без прав администратора
- Защищённый компонент аппаратных датчиков
- Автозапуск с Windows
- Ярлыки на рабочем столе и в меню «Пуск»

## Установка

Скачайте `TaskbarMonitorEnhanced_Setup_<version>.exe` из Releases и запустите его. Windows может запросить права администратора для установки защищённого компонента датчиков, но основное приложение продолжает работать без повышения привилегий.

Кандидат 1.2.0 прошёл локальную сборку, проверку детерминизма, визуальные проверки и контроль установленного runtime; публичным релизом он станет только после успешного CI для того же GitHub head и прохождения этапов публикации.
