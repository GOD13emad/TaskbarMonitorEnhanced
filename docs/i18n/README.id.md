# Taskbar Monitor Enhanced — Bahasa Indonesia

Taskbar Monitor Enhanced adalah monitor sistem ringan yang terintegrasi ke taskbar Windows. Informasi penting tetap terlihat tanpa perlu membuka jendela monitoring tambahan.

## Versi saat ini

**1.2.0 (public release)**

## Fitur utama

- CPU, RAM, disk, GPU, dan VRAM
- Kecepatan download dan upload terpisah
- Suhu CPU Package dan GPU
- 28 tema bawaan
- Grafik dan sparkline real-time
- Posisi kiri, tengah, atau kanan
- Lebar yang dapat diatur dan safe placement
- Menu klik kanan
- Pemulihan otomatis setelah Explorer restart
- Aplikasi utama berjalan tanpa hak administrator
- Komponen sensor perangkat keras yang terlindungi
- Start with Windows
- Shortcut Desktop dan Start Menu

## Instalasi

Unduh `TaskbarMonitorEnhanced_Setup_1.2.0.exe` dari Releases lalu jalankan. Windows mungkin meminta izin administrator untuk memasang komponen sensor perangkat keras yang dilindungi; aplikasi utama tetap berjalan tanpa elevasi.

Rilis publik 1.2.0 kini telah diterbitkan; deterministic build, bukti visual, kesehatan runtime terpasang, CI pada commit rilis yang tepat, dan verifikasi SHA-256 untuk ketujuh aset yang dipublikasikan semuanya PASS.
