# Taskbar Monitor Enhanced — Español

Taskbar Monitor Enhanced es un monitor ligero para la barra de tareas de Windows. Muestra la información que normalmente quieres consultar de un vistazo sin mantener otra ventana abierta.

## Versión actual

**1.2.0 (public release)**

## Funciones principales

- CPU, RAM, disco, GPU y VRAM
- Velocidades de descarga y subida por separado
- Temperaturas de CPU Package y GPU
- 28 temas integrados
- Gráficas y sparklines en tiempo real
- Posición izquierda, central o derecha
- Anchura ajustable y colocación segura
- Menú contextual con clic derecho
- Recuperación automática tras reiniciar Explorer
- Aplicación principal sin privilegios de administrador
- Componente protegido para sensores de hardware
- Inicio con Windows
- Accesos directos en Escritorio y menú Inicio

## Instalación

Descarga `TaskbarMonitorEnhanced_Setup_1.2.0.exe` desde Releases y ejecútalo. Windows puede solicitar permisos de administrador para instalar el componente protegido de sensores; la aplicación principal continúa ejecutándose sin elevación.

La versión pública 1.2.0 ya está publicada; superó la compilación determinista, las pruebas visuales, la salud del runtime instalado, el CI del commit exacto de la versión y la verificación SHA-256 de los siete assets publicados.
