# Taskbar Monitor Enhanced — العربية

Taskbar Monitor Enhanced أداة خفيفة لمراقبة النظام مباشرة من شريط مهام Windows، بحيث تبقى أهم معلومات الأداء ظاهرة من دون الحاجة إلى نافذة مراقبة منفصلة.

## الإصدار الحالي

**1.2.0 (public release)**

## أهم الميزات

- مراقبة CPU وRAM والقرص وGPU وVRAM
- عرض منفصل لسرعتي التنزيل والرفع
- حرارة CPU Package وGPU
- 28 سمة مدمجة
- رسوم حية وSparklines
- وضع يسار أو وسط أو يمين شريط المهام
- عرض قابل للتعديل ووضع آمن
- قائمة بالنقر بزر الفأرة الأيمن
- استعادة تلقائية بعد إعادة تشغيل Explorer
- التطبيق الرئيسي يعمل دون صلاحيات Administrator
- مكوّن محمي لمستشعرات العتاد
- التشغيل مع Windows
- اختصارات سطح المكتب وقائمة Start

## التثبيت

نزّل `TaskbarMonitorEnhanced_Setup_1.2.0.exe` من Releases وشغّله. قد يطلب Windows صلاحية Administrator لتثبيت مكوّن المستشعرات المحمي، بينما يبقى التطبيق الرئيسي غير مرفوع الصلاحيات.

الإصدار العام 1.2.0 متاح الآن؛ اجتاز البناء الحتمي والأدلة المرئية وصحة التشغيل وCI على commit الإصدار، كما تطابقت بصمات SHA-256 للأصول السبعة المنشورة.
