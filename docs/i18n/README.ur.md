# Taskbar Monitor Enhanced — اردو

Taskbar Monitor Enhanced Windows taskbar کے لیے ایک ہلکا system monitor ہے جو اہم hardware اور network information براہِ راست taskbar پر دکھاتا ہے، اس لیے الگ monitoring window کھلی رکھنے کی ضرورت نہیں رہتی۔

## موجودہ ورژن

**1.2.0 (public release)**

## اہم خصوصیات

- CPU، RAM، disk، GPU اور VRAM monitoring
- الگ download اور upload speed
- CPU Package اور GPU temperature
- 28 built-in themes
- live graphs اور sparklines
- taskbar کے left، center یا right پر placement
- adjustable width اور safe placement
- right-click menu
- Explorer restart کے بعد automatic recovery
- main app administrator privileges کے بغیر
- protected hardware-sensor component
- Windows کے ساتھ startup
- Desktop اور Start Menu shortcuts

## Installation

Releases سے `TaskbarMonitorEnhanced_Setup_1.2.0.exe` download کر کے چلائیں۔ Hardware sensor component install کرنے کے لیے Windows administrator approval مانگ سکتا ہے، جبکہ main application non-elevated رہتی ہے۔

عوامی 1.2.0 ریلیز اب شائع ہو چکی ہے؛ deterministic build، visual proof، installed runtime health، exact release-commit CI اور شائع شدہ تمام 7 assets کی SHA-256 digest verification PASS ہے۔
